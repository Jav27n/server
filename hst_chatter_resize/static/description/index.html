HST Chatter Resizer Backend

Description

Enterprise

A lightweight Odoo module that adds a resizable handle to the backend chatter panel. With this module installed, users can drag the panel's edge to make the chatter wider or narrower, fitting it to their own screen and workflow.

This module uses Odoo's standard chatter rendering for a smooth, native experience with no extra configuration needed. Simply install, and the resize handle appears automatically wherever the chatter is shown.

Features

  • → Adds a draggable resize handle to the chatter panel
  • → Lets users widen or narrow the chatter with a simple drag
  • → Works automatically on any backend view with a chatter panel
  • → Resizing only affects the chatter, the rest of the form stays unaffected
  • → No extra configuration needed — simply install and use

How It Works

Step Description
1. Install the Module Install HST Chatter Resizer Backend on your Odoo 19 instance
2. Open Any Record Navigate to a record with a chatter panel, e.g., Contacts, Sales Orders
3. Find the Resize Handle A draggable line appears along the edge of the chatter panel
4. Drag to Resize Click and drag the handle to widen or narrow the panel
5. Done Release to set the new width; it stays this way until you adjust it again
